# Arm fp16 width module

Width module at `vendors/arm/fp16`. It does not fill `vm_backend_ops` and
does not own `vm_fp16_t`. The core switch `VECMAT_ENABLE_FP16` builds the
scalar slot. This module overrides that slot when the CPU has `FEAT_FP16`.

Probe is `HWCAP_ASIMDHP` and `HWCAP_ASIMDFHM`. No MIDR.

- Neither bit: do not register. Note stays `fp16=scalar`.
- `ASIMDHP` only: convert to f32 and use f32 FMA. Note `fp16=neon-cvt`.
- Both: `FMLAL` / `FMLAL2` into f32 accumulators. Note `fp16=neon`.

`+fp16+fp16fml` is set on `neon.c` only. `+fp16` alone does not assemble
`vfmlalq_low` / `vfmlalq_high`.

## Build

```bash
cmake -S . -B build -G Ninja \
  -DVECMAT_ENABLE_FP16=ON \
  -DVECMAT_MODULES=arm/fp16
cmake --build build
```

`arm/fp16` without `VECMAT_ENABLE_FP16` is a configure error. On a host
without `ASIMDHP` the scalar slot stays. Loading this module does not
change `cortex-a5x`.
