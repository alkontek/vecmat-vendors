# Arm bfloat16

Width module for [Vecmat](https://github.com/alkavan/vecmat). Loaded as
`arm/bf16`. Requires `VECMAT_ENABLE_BF16=ON`.

Uses `vm_cpu_has(VM_CPU_ARM_BF16)` (core probes `HWCAP2_BF16`) and installs
a `BFDOT` GEMM slot when present. Otherwise, the scalar slot stays.

```bash
cmake -S vecmat -B build \
  -DVECMAT_ENABLE_BF16=ON \
  -DVECMAT_MODULES="arm/bf16" \
  -DVECMAT_MODULES_PATH=../vecmat-vendors
```
