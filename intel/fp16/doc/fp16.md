# Intel fp16 width module

Width module in the vendors tree (`vendors/intel/fp16`). It does not fill
`vm_backend_ops` and does not own `vm_fp16_t`. Accumulators stay f32.
AVX, AVX2, and AVX-512F do not do binary16 arithmetic.

- No F16C: do not register. Note stays `fp16=scalar`.
- F16C: 8-wide `vcvtph2ps` plus f32 FMA. Note `fp16=f16c`.
- AVX-512 FP16: 16-wide convert plus f32 FMA. Note `fp16=avx512fp16`.
  This is not AVX-512F and not AVX-512 BF16.

## Build

```bash
cmake -S . -B build -G Ninja \
  -DVECMAT_ENABLE_FP16=ON \
  -DVECMAT_MODULES=intel/fp16 \
  -DVECMAT_MODULES_PATH=/path/to/vecmat-vendors
cmake --build build
```
