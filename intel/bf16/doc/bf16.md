# Intel bfloat16

Width module for [Vecmat](https://github.com/alkavan/vecmat). Loaded as
`intel/bf16`. Requires `VECMAT_ENABLE_BF16=ON`.

Installs an AVX-512 BF16 GEMM slot when the CPU reports it. Otherwise, the
scalar slot stays.

```bash
cmake -S vecmat -B build \
  -DVECMAT_ENABLE_BF16=ON \
  -DVECMAT_MODULES="intel/bf16" \
  -DVECMAT_MODULES_PATH=../vecmat-vendors
```
